Plan & code-compliance QA

Catch code issues before they become comments.

The same construction-trained VLMs read the actual drawings — floor plans, elevations, sections, schedules — and reason about them against jurisdiction-specific code, so issues surface in seconds instead of weeks of review cycles.

A

Code-compliance review

Egress, setbacks, fire separation, energy, ADA, and structural callouts checked against the relevant code and local amendments.

B

Precedent-aware flagging

Pattern-matches against accepted and rejected plans in the same jurisdiction — fix the recurring comment before it lands.

C

Cross-sheet consistency

Catches dimensional, schedule, and callout mismatches across sheets — the silent reason plans bounce back.

D

Cited, explainable issues

Every flag carries a code-section citation and a visual annotation — defensible to the architect, traceable for the reviewer.
